# Warm Beer, Lousy Food

A deployable Vite/React clickdummy for shared restaurant bucket lists.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Create a GitHub repository named `warm-beer-lousy-food`.
2. Upload all files from this folder, preserving the folder structure.
3. In Vercel, choose **Add New → Project**.
4. Import the GitHub repository.
5. Vercel should detect **Vite** automatically.
6. Click **Deploy**.

No environment variables or database are required for this clickdummy.
